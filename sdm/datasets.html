Datasets and citations

Every model fitted here reads the datasets below from the boettiger-lab STAC catalog, where each is stored as H3-indexed parquet. Please cite the original sources when you use a result. How each layer enters a model is described in the data layers documentation.

CHELSA 2.1 bioclimatic variables climate predictors future scenarios

Services used by this page

Species distribution models are fitted by hexsdm (documentation). Species names are looked up with the GBIF species API, and queries run on the open duckdb-geo MCP server. The basemap is Esri World Light Gray Canvas (Esri, HERE, Garmin, © OpenStreetMap contributors), drawn with MapLibre GL JS.
